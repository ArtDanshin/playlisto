# Фронтенд проекта Playlisto

## Основная информация

Статическое веб-приложение (SSG) для работы с информацией о плейлистах, использующее данные из IndexedDB, внешних источников и файлов. Приложение построено на Next.js и может быть развернуто на любом статическом хостинге, включая GitHub Pages.

## Технологии

- `Next.js 15` - React фреймворк с поддержкой SSG
- `React 19` - UI библиотека
- `TypeScript` - Типизированный JavaScript
- `Zustand` - Менеджер состояния приложения
- `Tailwind CSS 4` - CSS фреймворк
- `Shadcn` - Библиотека компонентов
- `Storybook` - Управление библиотекой компонентов
- `IndexedDB` - Клиентская база данных
- `Spotify Web API` - Интеграция с Spotify
